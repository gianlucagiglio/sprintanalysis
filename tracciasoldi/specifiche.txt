Project Overview

We are building a personal finance analysis web application.

The application must allow the user to:

Upload financial transaction files exported from:

Bank account

Credit card

Process the files immediately after upload

Display transactions in separate sections

Generate a combined financial overview

Enable future financial clustering and spending analytics

This first version must NOT include authentication or a database.

All processing must happen in-memory on the frontend.

Future versions will introduce:

Supabase database

User authentication

Persistent financial history

Machine learning based expense classification

Project Setup

Claude must generate the project using:

npm create vite@latest finance-tracker -- --template react-ts

Then install dependencies:

npm install

npm install xlsx
npm install zustand
npm install recharts
npm install papaparse

npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

Install UI library:

npx shadcn-ui@latest init

Core Data Model

Define a Transaction type.

type Transaction = {
  id: string
  date: string
  description: string
  amount: number
  category?: string
  source: "bank" | "credit_card"
}

File Processing

When a file is uploaded:

Parse the Excel file

Normalize the data

Convert each row into a Transaction

Store the transactions in Zustand state

Processing must happen immediately in the browser.
