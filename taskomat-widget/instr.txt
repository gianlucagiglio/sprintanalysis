CONTEXT

We are building a React-based feature inside an application called Taskomat.

We need to implement a Project Creation Assistant Widget that allows users to create:

Customer

Project

Budget

Workunits

Tasks

Each Workunit can contain multiple Tasks.
Each Task has:

name (string)

estimatedTime (number, e.g. hours)

Backend APIs are NOT available yet.

We must simulate:

API layer

Application state (as if data is persisted)

A page where created data is displayed

GOAL

Build a complete frontend simulation including:

Wizard-based creation widget

Mock API layer

In-memory data store

A page that displays created projects

The system must behave like a real application.

TECH STACK

React (functional components)

Hooks only (useState, useReducer, useContext)

No class components

No heavy external dependencies

Clean, modular, production-ready code
